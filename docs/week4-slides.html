Implementation · 1

Artifacts

  • FileArtifactService — versioned, on disk
  • scoped user_id = client_id, session_id = None → outlives sessions
  • model sees compact refs only: name@v0 · 830 B · summary
  • full text fetched only when a question needs it
  • proof: prompt tokens 460 → 1,217 only on the fetch turn
Implementation · 2

Memory Bank

  • memorize_meeting → session ingested, LLM extracts facts
  • extraction is asynchronous — searchable seconds later
  • recall_client_memory — deliberate, visible tool call
  • scoped to the client account — shared across the team
  • Dilini records Monday → Kasun inherits Thursday
Implementation · 3

Scope & isolation

  • client_id set by calling code — never typed, never inferred
  • no client → session refused before the model runs
  • every tool re-checks scope; storage partitioned by it
  • automated leak test: memory + artifacts + live answer → exit 1 on any leak

Scars

Gotchas we earned

  • express-mode key → 403; ADC is the formal path
  • models on global, engine in us-central1 — two location settings
  • built-in memory tools scope by session owner — broke in web; fixed with explicit client scoping
  • consolidation latency — poll before recall
